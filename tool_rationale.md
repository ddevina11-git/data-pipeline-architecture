# Tool Rationale: Choosing the Right Tools for Data Projects

As a Project Manager, I might be asked to help teams decide which tools to use. Here is my honest, high-level understanding of common tools.

## Cloud Platforms

| Tool | What I Understand | When I Would Recommend |
|------|-------------------|------------------------|
| Azure | I have basic exposure through my bootcamp. Understand Data Factory, Blob Storage, Synapse. | If the company already uses Microsoft ecosystem |
| Snowflake | Understand it is a cloud data warehouse. Separates storage and compute. Good for scaling. | When data volume is large or unpredictable |
| AWS (S3, Redshift) | Know the names but less hands-on experience. | I would defer to engineers with AWS expertise |

## Data Integration & Transformation

| Tool | What I Understand | When I Would Recommend |
|------|-------------------|------------------------|
| dbt | Understand it is "transform after load" (ELT approach). Good for version control. | When team values SQL over Python |
| Azure Data Factory | Low-code ETL. Good for teams with less coding experience. | For Microsoft-shop companies |
| Apache Airflow | Open source orchestration. Powerful but requires maintenance. | When team has dedicated DevOps resources |

## Business Intelligence

| Tool | What I Understand | When I Would Recommend |
|------|-------------------|------------------------|
| Power BI | I have built dashboards in Power BI. Comfortable with DAX basics. | For executive dashboards; Microsoft shops |
| Tableau | Know it is strong for visual exploration. Less hands-on experience. | When team prioritizes complex visuals |

## My Honest Skill Level

I am not a tool expert. I am a Project Manager who has used these tools enough to:
- Participate in tool selection conversations
- Understand trade-offs between options
- Ask informed questions during vendor demos
- Respect that engineers have strong preferences

What I bring is not deep tool knowledge – it is the ability to facilitate the decision process, document requirements, and manage the implementation project.
